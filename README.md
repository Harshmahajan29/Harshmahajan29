## 🚀 Featured Project

### 🎓 WCE Admission Management System

A full-stack admission portal built for **Walchand College of Engineering, Sangli**, designed to handle live spot/ACAP round admissions for Maharashtra's engineering intake — a system built to serve a large student cohort under real deadlines.

**What it does:**

Manages student registrations across **5 admission tracks** — MHT-CET, JEE, Diploma, Non-CAP, and M.Tech Sponsored candidates <br>
Implements **multi-table backend routing** (CET → `spot_registrations`, JEE → `all_india`, OMS → `outside_maharashtra_candidates`, Diploma → `diploma_students`) <br>
Generates **Excel exports** for admin use via Apache POI (`SXSSFWorkbook`) for large datasets <br>
Includes a dedicated **admin dashboard** with a real-time seat availability matrix (10 branches × 10 reservation categories) <br>
Handles **conditional document upload logic** based on candidate category (caste certificates, NCL, PWD, Orphan, Defence quotas) <br>
Integrates **PhonePe payment gateway** for the M.Tech Sponsored Candidates portal <br>
Built with a fully responsive, institutionally-branded UI (custom crimson/navy/gold theme)

**Stack:** Java · Spring Boot · Vanilla JS (ES Modules) · HTML/CSS · Apache POI · PhonePe API
